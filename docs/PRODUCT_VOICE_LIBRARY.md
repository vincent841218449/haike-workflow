缓存逻辑位于 `Haike_video/backlot/studio_voice_samples.py`，回归入口为 `tests/backlot/test_studio_voice_samples.py`。预热失败不阻塞浏览列表，播放时可重新尝试；失败内容不会写成有效缓存。

## 用户流程与界面

管理菜单新增「资源库」。音色库顶部切换「系统音色」「个人音色库」，显示数量；支持名称/标签搜索、语言筛选。卡片显示名称、语言、标签、可用状态、试听和选择按钮。个人音色可重命名。

制作页「声音→选择音色配音」显示当前音色，提供试听与更换入口。更换时打开同一个音色库面板，能浏览两类音色、试听、克隆；选中后返回原制作页，文案、人物图、录音与素材保留。草稿保存具体音色标识，刷新恢复；更换账户导致音色不可用时要求重新选择。

克隆分为两步：

1. 填写名称、录音语言及可选标签，上传参考录音，播放核对，确认声音使用授权及提交阿里百炼。
2. 核对音色名称、存放位置和费用，确认创建。完成后进入个人音色库，首次合成试听另行确认费用。

参考录音支持5–60秒、10MB以内WAV/MP3/M4A，推荐10–20秒清晰单人朗读。后台转为24kHz、单声道、16bit WAV，临时原文件在转换后清理。录音播放明确标为「参考录音试听」，合成试听明确标为「已保存的合成试听」。

手机采用单列卡片，筛选与操作换行，弹窗内部滚动；继续使用项目原有品牌、菜单、按钮、字段和弹窗。

## 音色与费用

7个官方系统音色账户共享；已有自定义系统音色仍由管理员管理。个人音色绑定统一网关账户，只有本人可读取、选用、重命名及下载试听。供应商密钥留在服务器，浏览器使用平台音色标识。已有「海客验收音色」「猴哥」属于CosyVoice v3.5 Flash，按原编号导入；退役腾讯音色保留历史记录，继续禁止新调用。

CosyVoice创建音色免费，仍经报价与确认流程保存同一请求意图。个人/自定义音色首次合成试听按配音报价计费；成功后的音频缓存于服务器，重复播放和重新下载不产生新的供应商调用。已有试听可直接导入。系统自定义试听在所有账户之间共用缓存，个人试听按所属账户隔离。7个官方音色使用免费官方示例。

实际视频配音使用所选音色及绑定的确切模型，沿用原报价/确认/账本。系统默认音色变化不重定向已有音色标识；已确认报价冻结原音色。已有录音制作不调用TTS。

官方依据：[阿里百炼音色复刻](https://help.aliyun.com/zh/model-studio/voice-cloning-user-guide)。本轮未提交用户录音、创建真实新音色或执行收费试听。

## 服务合同

| 接口 | 用途 |
| --- | --- |
| GET `/v2/voices` | 本账户可用系统/个人音色及试听状态 |
| POST `/v2/quotes`，model `haike/voice-clone` | 验证本人录音、授权、名称及模型，免费克隆报价 |
| POST `/v2/voices/{id}/preview-quote` | 返回现有缓存/原任务，或首次试听报价 |
| GET `/v2/voices/{id}/sample` | 经过账户权限检查的缓存音频 |
| POST `/v2/voices/{id}/rename` | 本人音色重命名 |
| POST `/v2/voices/clone-jobs/{id}/query` | 未知提交按原任务专属前缀查询，禁止重新创建 |

工作台的 `/api/studio/voices/*` 通过服务端私有海客Key转发；本机持久意图、任务和缓存以当前Key身份隔离。SQLite事务串行确认；网络断开后恢复原意图，不能生成第二次收费任务。服务器以事务保护共享试听，拒绝重复接受已有试听的生成报价。

百炼读取录音使用单文件随机凭证，10分钟过期，数据库仅存凭证哈希；HTTPS地址不包含客户Key或供应商Key。凭证只能读取为该用户上传的这一份录音。试听结果下载仅接受阿里百炼官方结果OSS域名、HTTPS、公共IP，不跟随跳转；验证TLS、限制5MB，并保存本地私有副本。
