# 本地口播模板真实成片回归

范围是当前菜单的 25 个模板/画幅组合：基础 3 款、旧 ADu 21 种风格与画幅绑定、
MotionGit 612 仪器台竖屏完整包。全部输入来自已有配音、数字人、转写与本地素材；
不提交新 TTS、数字人、生图、视觉模型或采集请求，不操作云端或发布服务。

## 证据与复现

入口见 `Haike_video/docs/TEMPLATE_RENDER_QA.md`。隔离数据库通过正式
`ProductionQueueWorker` 调用原有生产器，测试项目不混入用户的日常创作任务。
每轮修复使用新目录，保留旧失败、原工程、最终 MP4、编码后代表帧和测量结果。
本机证据集中于 `output/template-render-matrix-20261016/`；完整目录含私人媒体，
被 Git 忽略，不能把源码仓库中的本说明当作视频证据。

旧 ADu 固定版本为 `f52490bd1ec37370091982d853990725b340f3f5` / 3.14.0-rc.1；
完整包为 MotionGit 612 仪器台 2.5.2。测试核对来源指纹和实际镜头组，
不修改第三方原始动画、签名核心或个人授权封套。

## 实际修复

- 已有分镜全部就绪时，按冻结草稿与素材 SHA 恢复本地合成，避免重新依赖在线理解服务。
- 情境视频填满素材窗口，按实际主体焦点取景；截图、标志和证据保持完整。
  宽幅版为多人竖片增加显示高度并避让字幕，卡片窄窗放不下多人时使用忠于原文的文字镜头。
- 基础口播支持明确的文字镜头；必须采用的用户素材仍要真实出现，不能用文字冒充。
  新素材审核排除无关讲师口播及带大字幕的二次剪辑。
- 显示字幕回绑定用户原文，保留真实识别时钟，修正同音字及误分词。
- 纸面聚合的原生字幕辅助器要求 `sp` 字段，句级字幕显式传空数组，避免渲染崩溃，
  不编造逐字时间。其旧样式还隐藏统一字幕父容器；在生成工程中另加交付字幕样式，
  显示输出时钟字幕并隐藏内部重复层，不改作者原始场景或样式文件。
- 仪器台竖屏字幕使用中央面板与下方卡片间的单行安全区；贴纸交接组字幕避开底部标签，
  不改变同风格其他镜头的字幕位置。
- MotionGit 固定组校验内外两层实际预览图片和工程指纹；核验同一份图片后同步状态，
  保留原生审片闸门。
- 按 ADu 交付合同测量并归一化最终编码音轨，目标 -15.5 LUFS / -1.2 dBTP，
  最终 I 为 -16 至 -15、TP 不超过 -0.5。只复制视频流，保留原人物、声音和动作速度。
  原始渲染与交付 MP4 分别记录摘要，恢复时不会把声音处理误认为原生渲染失效。

## 样片对照的判断口径

“由作者原生引擎执行”和“与菜单演示逐镜相同”分别核对。固定组测试使用作者完整动作及
在真实语音停顿结束的短口播片段；基础模板和自由口播组件路线使用约 53 秒整条原声。
视觉夹具中的内容角色与数量是显式测试声明，不是对任意文案的自动语义通过证明。

- 连续形变另测原生 `claim-into-container`，核对样片的白底形变，不能只用其黑底拆分组代表整款。
- 纸面聚合分别核对网络聚合、日历/内容交付；纸箱动作属于后一个组，
  不用绿色网络镜头冒充纸箱片段。
- 贴纸演出另测角色/物体交接组；已有用户与示例人物图片替代作者私人卡通角色，
  角色画风不同不等于未执行原动作。
- 仪器台分别测试固定原生配方和官方组件路线；后者适合自由口播，不能宣称复现前者全部固定编舞。

## 本机结果

25 个组合全部实际出片，另补 5 个组/工作流对照，共 30 条最终测试片：
4 条约 53 秒完整口播、26 条完整原生动作片段。30/30 通过完整解码、H.264/AAC、
尺寸/帧率、声画时长和编码后响度检查，均核对实际代表帧；声画流时长最大差 0.667 ms，
I 为 -15.98 至 -15.31 LUFS，最高真峰值 -1.0 dBTP。原母版 SHA 未变，新增付费调用 0。
本机索引为 `output/template-render-matrix-20261016/验收报告.md`，包含每片 MP4、画面与差异说明；
机器证据为同目录 `summary.json`，旧失败与旧版仍保留。

后端 181 项、前端 38 项、生产构建和源码检查通过；本机 4188 保持原草稿与任务记录。
测试在隔离队列完成，没有把全部测试片导入日常任务，也没有宣称逐片浏览器播放验收。

尚未导入的其他 12 个新版个人包、旧库全部 101 个子组和全部 70 个组件变体不在本轮逐项验收范围。
抽帧、全解码与编码后音频测量不冒充完整连续听音；报告保留 `listened: false`。
本地结果不授权新增费用、上线或发布，不改写原未知供应商回执。
